The High-End Wingmen
Premium Audiobook Production Pack V2

33 narration-ready tracks, German and English, designed for ElevenLabs Studio or the included API renderer.

Fastest route: Studio

  1. Open ElevenLabs Studio and create a New audiobook.
  2. Import 01_Studio_Import/High_End_Wingmen_Audiobook_Studio_Import_v2.docx.
  3. Cast at least three German male narration voices using 03_Casting/01_Bilingual_Casting_Script.txt.
  4. Use Multilingual v2 for the full book.
  5. Upload the pronunciation file from 04_Pronunciation.
  6. Render State & Flow and English Field Scripts as full test chapters before converting everything.

Recommended voice

Male, 35–45, native or near-native German, calm, confident, warm, conversational and slightly dry. No radio-ad voice, no shouting coach and no exaggerated seduction performance.

Alternative: API

The included renderer creates three casting tests and then all chapter MP3s. It reads the API key only from the environment.

python 05_API_Renderer/render_elevenlabs.py cast --render 3
python 05_API_Renderer/render_elevenlabs.py render
